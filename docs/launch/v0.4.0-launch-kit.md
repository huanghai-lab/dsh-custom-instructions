## GitHub Discussions / DSH Discord（中文）

DSH 的全局 `AGENTS.md` 很有用，但手改文件不方便，也容易在多个窗口之间互相覆盖。我发布了 dsh-custom-instructions v0.4.0，把全局指令、模板、Markdown 预览、历史恢复和安全导入导出放进 DSH Web 设置页。

这一版重点不是“多一个编辑框”，而是把数据安全补完整：每次写入都校验磁盘 revision，冲突时保留草稿；导入先整体校验，失败自动回滚；模板文件名经过 Base64URL 编码；真实 DSH tarball E2E 在隔离 profile 中运行。

安装：`dsh plugin --profile web add @huanghai-lab/dsh-custom-instructions`

目前只兼容 DSH 0.1.1-rc.2。欢迎反馈真实安装问题、模板用法和迁移体验。

## GitHub Discussions / Reddit（English）

I released dsh-custom-instructions v0.4.0, a safe instruction manager inside DSH Web. It provides a global AGENTS.md editor, reusable templates, the official Markdown preview, version history, and portable import/export.

The release focuses on data safety: disk-derived revisions prevent silent multi-window overwrites, imports are validated before a transactional merge, template filenames are Base64URL-encoded, and the packed plugin is exercised against a fresh isolated DSH 0.1.1-rc.2 profile in CI.

Install: `dsh plugin --profile web add @huanghai-lab/dsh-custom-instructions`

I would value reproducible installation reports and concrete workflow feedback. DSH 0.1.1-rc.2 is the only supported runtime for this release.
